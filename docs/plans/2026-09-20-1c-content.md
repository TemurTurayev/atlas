# Atlas 1C — Content: the remaining 37 MVP skills

> **For agentic workers:** Follow the existing template contract and make the generic harness pass. This plan is a per-skill brief, not transcribed code: four templates already exist as worked references, and `harness.test.ts` enforces the quality bar mechanically for every new file.

**Goal:** A generator + theory card for every MVP skill: all 24 foundations (week 0) and all 17 week-1 skills. Four already exist (`linear_eq`, `quadratic_eq`, `factor`, `set_ops`), so 37 remain.

**Prerequisites:** plans 1A and 1B done. Read first:
- `src/core/templates/types.ts` — the contract (`SkillTemplate`, `Problem`, `AnswerSpec`).
- `src/core/templates/week0/quadratic_eq.ts` — reference for `numberSet` + tiers + solution steps.
- `src/core/templates/week0/factor.ts` — reference for `expression` with `form: 'factored'`.
- `src/core/templates/week1/set_ops.ts` — reference for `finiteSet`.
- `src/core/math/{latex,poly,rational}.ts` — LaTeX/number helpers. Reuse them; do not reinvent formatting.
- `src/core/checker/` — what each answer kind accepts.

**Rules for every template**
1. File `src/core/templates/week<N>/<skill_id>.ts`, exporting `export const template: SkillTemplate` (auto-registered by the glob).
2. Build the problem **backwards from a nice answer** (integer roots, exact trig angles, clean logs). Reject degenerate draws with `rng.intExcept`.
3. Deterministic: only use the injected `rng`. No `Math.random`, no `Date`.
4. `statement.en` is exam-style English, `statement.ru` the same problem in Russian. Formulas inside `$…$`.
5. `theory`: 3–6 lines of Russian, key formula, 1–2 typical mistakes, English term in parentheses on first use.
6. `solution`: the steps a person writes on paper, each `{ru, tex?}`. `hints`: 2–3, from gentle to specific.
7. `expectedSeconds`: honest minutes-per-tier for a rusty adult (T1 ≈ 30–60 s, T2 ≈ 60–120 s, T3 ≈ 120–240 s).
8. For `expression` answers set `variables` and, when the reference is undefined near 0 or negatives (roots, logs, rational functions), set `domain` (e.g. `{ x: [1.5, 4] }`).
9. Never loosen the checker to make a template pass — fix the template.
10. Run `npx vitest run src/core/templates` after each file; the harness checks determinism, KaTeX rendering, and that the checker accepts the reference answer and rejects a perturbation.

**Per-skill test:** add one assertion per skill in a `*.samples.test.ts` file for your batch that verifies the mathematics independently of the generator (e.g. substitute the answer back into the statement, or recompute the expected value a second way). Follow `src/core/templates/samples.test.ts`.

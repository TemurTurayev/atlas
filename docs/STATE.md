## Что сделано (MVP закрыт)
- Ядро: граф 125 навыков, генераторы задач, проверка ответов (Compute Engine 0.131.3, численная выборка), FSRS на навык, адаптивный движок (экспресс → урок → освоено, уровни, прыжки, ремонт), серия дней, прогноз балла, хранение в IndexedDB с экспортом/импортом.
- Контент: **57 навыков** — школьная база (неделя 0), недели 1–3 курса; теория, подсказки и разборы на английском.
- Неделя 2 (векторы): компоненты и умножение на число, длина и единичный вектор, скалярное произведение, угол между векторами, векторное произведение, параметрические прямые, плоскости и пересечение прямой с плоскостью, геометрия систем (одна точка / нет решений / бесконечно много). Для каждой партии задач, кроме общего стенда, написан samples-тест, который independently пересчитывает ответ.
- Интерфейс: главная, забег, карта, тренировка отдельного навыка, настройки; PWA (ставится в Dock).
- Второй круг ресёрча внедрён: короткий забег «5 минут», предсказание результата перед миксом, возврат после пропуска на второй день без вины, баннер свежего старта, напоминание решать на бумаге.
- «Показать решение»: полный разбор по запросу; нажатие = задача засчитана нерешённой (движок вернёт похожую); после верного ответа разбор доступен по желанию; `Problem.alternative` — второй способ решения (сделан для `quadratic_eq` и `sim_eq_2x2`).
- **Пробный экзамен** (`src/core/exam/`, экраны `Exam.tsx` / `ExamResults.tsx`): вся работа выдаётся сразу, таймер на виду, без подсказок и без обратной связи до сдачи; по задачам можно ходить, пропуски — в минус. Открывается с 8 освоенных навыков, длина подгоняется под объём (шаг 5 минут, максимум 60). Сдача ставит оценку всем проверенным навыкам (промах → карточка возвращается через дни), начисляет XP, засчитывает день и пишет результат в `examHistory`. Время вышло — работа сдаётся сама, даже если приложение было закрыто.
- **Журнал ошибок** (`src/core/mistakes/`, экран `Mistakes.tsx`): промах по освоенному навыку (повторение, микс, экзамен) сохраняется вместе с сидом задачи; забег начинается с этих тем, первый возврат — ровно та же задача, дальше свежие того же типа; два чистых ответа закрывают запись.
- Главный экран: три шкалы — «Exam forecast» (весь курс, порог 45 %), «Material in the app» (то, чему приложение уже умеет учить: эта цифра растёт каждый день) и «Foundations». В забеге виден счётчик «3 / 8», после ответа Enter переходит к следующей задаче.
- Починено по ходу: поле ввода формул, удалённое с экрана «в фокусе», роняло приложение (MathLive держит глобальную ссылку на сфокусированное поле — `MathInput` её освобождает); service worker стоял на `prompt` и опубликованная версия навсегда залипала на первой закэшированной сборке — теперь `autoUpdate`.
- Проверки: 725 тестов, typecheck чистый, Playwright-смоук проходит.

## Важные решения, которые нельзя случайно отменить
- Никакого свободного ИИ-решателя: в RCT доступ к GPT-4 поднял домашку на 127 %, а закрытый экзамен — на 0. Подсказки только статические и только после попытки.
- Никаких лиг и рейтингов; главная метрика — прогноз балла, не XP.
- Тренировка с карты намеренно не влияет на повторения и не даёт XP.
- Версия Compute Engine закреплена точно (0.131.3): у библиотеки по нескольку релизов в день.
- Экзаменационные формулировки на английском, объяснения на русском.
- Код отформатирован вручную в стиле `.prettierrc` (140 колонок, без точек с запятой). **Не запускать `npx prettier --write` без этого конфига** — дефолты переформатируют весь проект.
- Таймер на пробном экзамене не прячем (см. решения второго круга).
- Весь пользовательский текст на английском; русский в `src/` не должен появляться (`grep -r '[А-Яа-яЁё]' src` = 0).
- Неделя 3 (матрицы): задачи на исключение строятся обратным ходом из верхнетреугольной цели целочисленными операциями — множители заведомо целые; обратные матрицы — из произведения элементарных, поэтому определитель ±1. Общее решение системы в свободной форме не спрашиваем: только число решений или частное решение, зафиксированное условием.
- Под полем ответа есть ряд кнопок с символами (√, ⁿ√, дробь, степень, π, ∞, ±) — в векторе и матрице он выключен.
- Плоскость не спрашиваем уравнением целиком: любое кратное уравнения задаёт ту же плоскость, проверяльщик не может судить честно. Спрашиваем нормаль или константу.
- Service worker в режиме `autoUpdate`, плюс перезагрузка по `controllerchange` в `main.tsx`: иначе опубликованная версия залипает.

## Что сделано (MVP закрыт)
- Ядро: граф 125 навыков, генераторы задач, проверка ответов (Compute Engine 0.131.3, численная выборка), FSRS на навык, адаптивный движок (экспресс → урок → освоено, уровни, прыжки, ремонт), серия дней, прогноз балла, хранение в IndexedDB с экспортом/импортом.
- Контент: **41 навык** — вся школьная база (неделя 0) и вся неделя 1 курса.
- Интерфейс: главная, забег, карта, тренировка отдельного навыка, настройки; PWA (ставится в Dock).
- Второй круг ресёрча внедрён: короткий забег «5 минут», предсказание результата перед миксом, возврат после пропуска на второй день без вины, баннер свежего старта, напоминание решать на бумаге.
- «Показать решение»: полный разбор по запросу; нажатие = задача засчитана нерешённой (движок вернёт похожую); после верного ответа разбор доступен по желанию; `Problem.alternative` — второй способ решения (сделан для `quadratic_eq` и `sim_eq_2x2`).
- Проверки: 697 тестов, покрытие ядра ~98 %, typecheck чистый, Playwright-смоук проходит.

## Важные решения, которые нельзя случайно отменить
- Никакого свободного ИИ-решателя: в RCT доступ к GPT-4 поднял домашку на 127 %, а закрытый экзамен — на 0. Подсказки только статические и только после попытки.
- Никаких лиг и рейтингов; главная метрика — прогноз балла, не XP.
- Тренировка с карты намеренно не влияет на повторения и не даёт XP.
- Версия Compute Engine закреплена точно (0.131.3): у библиотеки по нескольку релизов в день.
- Экзаменационные формулировки на английском, объяснения на русском.

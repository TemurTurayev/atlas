# Атлас — дизайн (спецификация)

_Дата: 2026-09-19 · Статус: утверждена концепция «вариант C» · Автор: Claude + Темур_

## 1. Цель

Персональное приложение для Mac (и iPhone), которое затягивает как игра и готовит Темура к письменному экзамену
**MQLS-CO-01 Guided Self-Study, часть Math/Physics** (60 минут, порог 45 %, ориентировочно конец января 2027).
Темы экзамена — недели курса 1–7, 9, 10, 12–14 (недели 8 и 11 исключены, письмо Винклера 14.09.2026).

**Успех =**
1. Темур занимается почти каждый день по 35–45 минут и не бросает после 3–4 недель.
2. Прогноз балла растёт и к экзамену стабильно выше 60 %.
3. Задачи в приложении по форме совпадают с экзаменационными (вычисления, запись ответа), а не только «интуиция».

## 2. Пользователь и ограничения

- Врач, школьную алгебру не трогал ~10 лет. Хорошо знает медицину/биостатистику на уровне клиники.
- MacBook Air M4, macOS 26; Xcode не установлен. Хочет «приложение для мака».
- Экзамен на английском → условия задач на английском, объяснения на русском.
- Контент курса выходит по неделе в неделю (сейчас неделя 1–2) → контент приложения тоже можно выпускать поэтапно.
- **Явное требование:** начинать с базы; если справляется хорошо — быстрее давать следующие, более сложные темы.

## 3. Принципы обучения (из ресёрча, кратко)

| Принцип | Как реализуем |
|---|---|
| Самопроверка сильнее перечитывания | Всё обучение — решение задач с проверкой ответа |
| Интервальные повторения | FSRS на каждый навык, свежая задача при каждом повторе |
| Перемешивание | Блок «Микс» в каждом забеге |
| Пример → пример с пропусками → сам | Режим «Урок» для нового навыка |
| Освоение до перехода дальше | Навык открывается, только когда освоены все пререквизиты |
| Успешность 80–85 % | Адаптивные уровни сложности внутри навыка |
| Игра = сама практика | Лаборатории (этап 2+) по схеме «предскажи → поиграй → докажи» |
| Награда информирует, а не подкупает | Главная метрика — прогноз балла, а не очки |

**Не делаем:** лиги и рейтинги, «жизни», которые блокируют практику после ошибок, XP за повтор лёгкого, видимый счётчик XP во время решения, уведомления с чувством вины, награды «мини-игрой после математики», сессии > 60 минут.

## 4. Игровой цикл

### 4.1 Главный экран
- Кнопка «Начать забег» (или «Продолжить»).
- Прогресс дня (XP к цели 40), серия дней 🔥 и число заморозок.
- Две шкалы: **«База»** (% освоенных навыков недели 0) и **«Экзамен»** (прогноз балла с отметкой порога 45 %).
- Мини-карта: следующие 3–5 доступных навыков (вся карта — отдельный экран).

### 4.2 Забег дня (35–45 мин)
Забег — это очередь заданий, которую строит `session`:

1. **Разминка** (≤ 8 заданий, ~10 мин): навыки, которым пора повториться по FSRS; сначала с самой низкой вероятностью вспомнить; навыки из разных недель вперемешку.
2. **Новое** (1–3 навыка): навыки на «фронтире» (все пререквизиты освоены). Каждый проходит через экспресс или урок (см. §5).
3. **Микс** (4–6 заданий): недавно освоенные навыки вперемешку с похожими на вид, но разными навыками.
4. **Итог**: что окрепло, изменение прогноза, серия, сколько повторов завтра.

Забег можно прервать в любой момент: прогресс сохраняется после каждого задания. Если XP дня ≥ 60, приложение предлагает остановиться («остальное в копилке»).

### 4.3 Задание
- Условие на английском (KaTeX), кнопка «RU» показывает перевод.
- Ввод ответа — поле формул MathLive (физическая клавиатура: `sqrt`, `pi`, `^`, `/`, `infty`), для интервалов — конструктор интервалов, для выбора — кнопки.
- «Проверить». Ответ неправильной формы (например, нужен набор корней, а введено одно выражение) — дружелюбное сообщение, **не считается ошибкой**.
- «Подсказка» (2–3 уровня, статические из шаблона). Использование подсказки снижает оценку для FSRS.
- После ответа — «Разбор» (пошаговое решение из генератора). При ошибке разбор показывается сразу, затем даётся **задача-близнец** (тот же навык и уровень, новые числа).

### 4.4 Серия дней
- День засчитывается при ≥ 5 решённых заданиях (≈ разминка).
- Заморозки: максимум 2, +1 за каждые 7 дней серии. Пропуск дня тратит заморозку автоматически.
- Никаких сообщений с чувством вины: при обрыве — «Новая серия начинается сегодня».

### 4.5 XP и прогноз
- **XP** ≈ минуты сосредоточенной работы: за верный ответ с первой попытки `max(1, round(expectedSeconds/60))`, со второй — половина, после показа ответа — 0. Повторное решение уже освоенного навыка вне расписания XP не даёт. Цель дня — 40 XP (настраивается).
- **Прогноз «Экзамен»** = Σ по экзаменационным неделям `w`: `вес_w × среднее_по_навыкам_w(p_s)`, где `p_s` = текущая вероятность вспомнить (FSRS retrievability) для освоенного навыка и 0 для неосвоенного или ещё не реализованного. Веса недель по умолчанию равные (1/12), high-yield-навык внутри недели весит ×2. Честно: пока реализована только неделя 1, прогноз не превысит ~8 %.
- **Шкала «База»** = доля освоенных навыков недели 0, взвешенная по `p_s`.

### 4.6 Позже (не в MVP)
- **Босс** каждые ~150 XP: 15 минут, экзаменационный формат, без подсказок; раз в месяц — полный пробный экзамен.
- **Лаборатории** (этапы 2–5): «Трансформер» (матрицы/det), «Охота на собственные векторы», «Эпидемия» (SIR), «Скрининг» (Байес/PPV), «Орбита», «Молекулы в коробке».
- **Claude-репетитор** (этап 2): многоуровневые сократические подсказки через API (Haiku 4.5), никогда не выдаёт ответ; правильность решает только проверщик.

## 5. Адаптивная прогрессия (ключевое требование)

### 5.1 Состояния навыка
```
locked ──(все пререквизиты mastered)──▶ available ──▶ express ──(2/2)──▶ mastered
                                                         │
                                                         └─(ошибка)─▶ lesson ──(освоил)──▶ mastered
mastered ──(FSRS: пора)──▶ повтор ──(провал)──▶ mastered + флаг repair
```
- `implicit` — навык зачтён не напрямую, а через прыжок (§5.4). Его FSRS-карточка стартует с оценкой Hard → ранний первый повтор («проверим позже»).

### 5.2 Уровни сложности (tiers)
У каждого шаблона 3 уровня:
- **T1** — один шаг, маленькие «удобные» числа (разогрев).
- **T2** — стандарт, как в разобранных примерах хендаута.
- **T3** — экзаменационный: комбинированный или «неудобный» вариант (например, биквадратное уравнение, параметр в дискриминанте).

Навык считается освоенным на T2. T3 появляется в повторах, когда стабильность FSRS-карточки > 14 дней, и в боссах.

### 5.3 Экспресс-проверка = старт с базы
Первая встреча с любым новым навыком — **экспресс**: 2 задачи уровня T2 без урока и без подсказок наперёд.
- Обе верны с первой попытки без подсказок → навык `mastered` (FSRS: первая оценка Good; если обе быстрее `expectedSeconds` — Easy). Показ: «Экспресс! ⚡ Навык засчитан».
- Любая ошибка или подсказка → переход в **урок** (§5.5), без штрафа.

Так «калибровка» не отдельный тест: Темур идёт с самой базы, и всё, что он помнит, пролетает по 2 задачи на навык.

### 5.4 Прыжок
- Условие: 3 экспресса подряд (счётчик `expressStreak`).
- Предложение (можно отказаться): «Прыгнуть вперёд?» **Лестница** — фиксированный топологический порядок навыков (по неделе, затем по глубине в графе). Пусть `f` — индекс первого неосвоенного навыка лестницы. Кандидаты — неосвоенные навыки с шаблоном и индексом в `(f, f + jumpStride]`; цель — кандидат с наибольшим числом неосвоенных предков (при равенстве — с большим индексом).
- 2 задачи T2 из целевого навыка. Обе верны → цель и **все её неосвоенные предки** становятся `mastered` с флагом `implicit`. `jumpStride` удваивается (4 → 8 → 12, максимум 12).
- Ошибка → без штрафа, `jumpStride` = 4, `expressStreak` = 0, обычный ход.

### 5.5 Урок
1. Мини-теория (RU, 3–6 строк, ключевая формула, типичные ошибки).
2. Разобранный пример (генератор, T1, все шаги).
3. Пример с пропусками: те же шаги, последние скрыты, ввести финальный ответ.
4. Практика с адаптивным уровнем: старт T1; 2 верных подряд → T2; ошибка на T2 → следующий T1.
5. Освоен, когда среди последних 4 заданий уровня T2 не менее 3 верных.

### 5.6 Ремонт (движение вниз)
- 2 ошибки подряд в уроке на T1 **или** провал повтора освоенного навыка → проверяются пререквизиты: сначала `implicit`, затем с наименьшей вероятностью вспомнить (retrievability).
- Каждый такой пререквизит получает экспресс-проверку прямо в забеге. Провал → он снова `lesson` («ремонт»), а зависимые навыки ждут.
- Формулировки — «ремонт», «укрепляем», никогда «это школьная программа».

### 5.7 Темп (momentum)
Скользящая точность последних 20 оценённых заданий:
- ≥ 90 % → до 3 новых навыков за забег, прыжки разрешены.
- 70–90 % → 2 новых навыка.
- < 70 % → 1 новый навык, больше повторов, практика стартует с T1.

## 6. Контент

### 6.1 Граф навыков
- Полный граф — 125 навыков (неделя 0 = школьная база + 12 недель курса), у каждого: `id`, названия RU/EN, неделя курса, пререквизиты, флаг high-yield.
- Источник — ресёрч «knowledge graph» (этот документ, приложение A). Граф ацикличен, пререквизит никогда не из более поздней недели (проверяется тестом).
- Навык без шаблона показывается на карте как «скоро».

### 6.2 Шаблон задачи (генератор)
Каждый реализованный навык = шаблон-генератор:
- Детерминирован: `(seed, tier) → Problem`, ГПСЧ с сидом (mulberry32).
- **Строится от ответа назад**: сначала выбирается «красивый» ответ (целые корни, рациональные значения, табличные углы), потом условие.
- Возвращает: условие EN/RU, спецификацию ответа, шаги решения (RU-текст + LaTeX), 2–3 подсказки, `expectedSeconds`.
- Отбрасывает вырожденные случаи (a = 0, повторяющиеся корни, если не задумано).

### 6.3 Мини-теория
Файл на навык: 3–6 строк RU, формула, 1–3 типичные ошибки. Термины с английским в скобках («дискриминант (discriminant)»).

## 7. Проверка ответов

Модуль `checker/` — единственное место, решающее «верно/неверно».

1. Разбор LaTeX из MathLive — собственным экземпляром **Compute Engine, закреплённая версия 0.131.3** (не `mf.expression`: MathLive содержит старую версию CE). Два разбора: канонический (для значения) и сырой `canonical:false` (для проверки формы).
2. Проверка формы («нужен набор из 2 чисел») → дружелюбное сообщение, не ошибка.
3. Эквивалентность выражений — **численная выборка**: 16 точек с сидом, избегая 0 и ±1, в области определения шаблона; пропуск точек, где эталон не определён; нужно ≥ 8 валидных; допуск `|a−b| ≤ 1e-8·max(1,|b|)`.
4. Виды ответа в MVP:
   - `number` — точное значение (дроби, корни, π, e) или десятичное с допуском;
   - `expression` — выражение от переменных (+ правила формы: `factored`, `expanded`, `simplified`, `exact`);
   - `numberSet` — набор чисел без порядка (корни); сообщается, каких не хватает и какие лишние;
   - `interval` — объединение интервалов из конструктора; сравнение концов и открытости;
   - `finiteSet` — конечное множество (числа или пары) для задач на множества;
   - `choice` — выбор варианта.
5. Детекторы типичных ошибок (знак, забытый множитель, обратная величина) → конкретная обратная связь («похоже, потерян знак»).
6. Золотой набор ≥ 100 пар «эквивалентно / не эквивалентно»; прогоняется при любом обновлении CE.

Известная особенность: `\ln 4 \cdot 5` разбирается как `ln(20)`; в подсказке к полю ввода — «коэффициент пиши перед функцией: 5\ln 4».

## 8. Архитектура

Чистое TypeScript-ядро без React (всё тестируется юнит-тестами) + тонкий UI.

```
src/
  core/
    random/      ГПСЧ и хелперы (randInt, pick, shuffle)
    math/        точная арифметика: рациональные, многочлены, LaTeX-форматирование
    graph/       данные графа (125 узлов), предки/потомки/лестница/фронтир
    templates/   генераторы: week0/*, week1/* + registry
    checker/     разбор (CE), эквивалентность, виды ответа, форма, диагностика
    learner/     состояния навыка, экспресс/урок/уровни/прыжок/ремонт/темп (чистый редьюсер)
    scheduler/   обёртка ts-fsrs: карточка на навык, оценка из попытки
    session/     сборка забега, выбор следующего задания
    forecast/    прогноз балла и шкала «База»
    streak/      серия, заморозки
  data/          Dexie: таблицы, репозитории, экспорт/импорт JSON
  ui/            экраны: Home, Run, Map, Skill (теория), Settings; компоненты: MathInput, IntervalBuilder, Tex
  content/       мини-теория по навыкам (RU)
```

**Поток данных:** UI → `store` (Zustand) → `session.next()` выдаёт `(skillId, seed, tier, mode)` → `templates` генерирует `Problem` → UI показывает → ответ → `checker` → `Attempt` → `learner.applyAttempt()` (новое состояние навыка) + `scheduler` (FSRS) → запись в Dexie → `session.next()`.

**Ключевые интерфейсы** (эскиз, окончательно — в плане):
```ts
type Tier = 1 | 2 | 3
interface SkillTemplate {
  skillId: string
  expectedSeconds: Record<Tier, number>
  generate(rng: Rng, tier: Tier): Problem
}
interface Problem {
  statement: { en: string; ru: string }      // текст с $…$ LaTeX
  answer: AnswerSpec
  solution: { ru: string; tex?: string }[]
  hints: string[]                             // RU
}
interface Attempt {
  skillId: string; seed: number; tier: Tier
  mode: 'express' | 'lesson' | 'review' | 'mix' | 'jump' | 'repair'
  correct: boolean; hintsUsed: number; seconds: number; at: number
}
```

## 9. Данные (Dexie / IndexedDB)

- `skillStates`: skillId, status, implicit, repair, lessonHistory, tier, fsrsCard, masteredAt.
- `attempts`: журнал всех попыток (для статистики и будущей подстройки FSRS).
- `days`: дата, XP, число заданий, засчитан ли день.
- `meta`: серия, заморозки, `expressStreak`, `jumpStride`, настройки (дата экзамена, цель XP, звук).
- `navigator.storage.persist()` при первом запуске; экспорт/импорт всего в JSON (кнопка в настройках + напоминание раз в неделю).

## 11. Тестирование

- **Шаблоны:** для каждого навыка и уровня — 500 сидов: задача генерируется без исключений, LaTeX разбирается, проверщик принимает эталонный ответ, отвергает искажённый (знак, ±1), числа в заданных рамках «красоты».
- **Проверщик:** золотой набор ≥ 100 пар + тесты каждого вида ответа.
- **Learner:** сценарии экспресс → mastered, экспресс → урок, прыжок (успех/провал), ремонт, темп.
- **Scheduler/session/forecast/streak:** юнит-тесты на чистых функциях с фиксированным «сегодня».
- **Граф:** ацикличность, существование всех пререквизитов, неделя пререквизита ≤ недели узла.
- **E2E (Playwright):** первый запуск → забег → экспресс проходит → навык освоен → перезагрузка сохраняет прогресс.
- Покрытие ядра (`src/core`) ≥ 80 %.

## 13. Риски и открытые вопросы

| Риск | Мера |
|---|---|
| Формат экзамена неизвестен точно | Темур спрашивает Винклера об образце, калькуляторе, листе формул, таблицах; веса прогноза настраиваемые |
| Compute Engine меняется очень быстро | Точная версия, всё за интерфейсом `checker/`, золотой набор |
| Неверная проверка правильного ответа → фрустрация | Численная выборка + кнопка «Я прав» (логирует случай → новый тест) |
| Хранилище Safari-приложения не синхронизируется и может быть очищено | `persist()`, еженедельное напоминание об экспорте |
| Спад мотивации на 4–8 неделе | Лаборатории и боссы этапов 2–3 приходятся на это окно |
| Контент недели курса отстаёт от курса | Этапы привязаны к датам (§12) |

**Дата экзамена** неизвестна — по умолчанию 2027-01-29, меняется в настройках.

# Атлас — решения по итогам второго круга ресёрча (20.09.2026)

Три ресёрча: (1) что нового в геймификации математики 2023–2026, (2) какие готовые компоненты можно взять вместо своего кода, (3) что удерживает ежедневную привычку у взрослого. Полные отчёты — в истории сессии; ниже только решения.

## Что делаем сейчас (дёшево и доказано)

| Решение | Почему | Статус |
|---|---|---|
| **Предсказание перед миксом**: «сколько из 5 решишь верно?» → сравнение в итогах | Оценка уверенности ДО ответа улучшает калибровку и бьёт по иллюзии знания (Bjork; Gruetzemacher 2024, ~30 мин тренировки улучшают Brier score) | внедряется |
| **Короткая версия забега (5 минут)** | «Минимальная сессия» — главный инструмент против пропусков; доступна в один тап | внедряется |
| **Сигнал на второй день пропуска, без вины** | Возврат резко падает после второго пропуска подряд (81 % → 71 %); формулировка без «ты потерял серию» — эффект «да и ладно» (Polivy & Herman) | внедряется |
| **Баннер «свежий старт»** (понедельник, 1-е число, после паузы ≥3 дней) | Fresh start effect (Dai, Milkman & Riis) | внедряется |
| **Итоги забега с конкретикой**: «прогноз +1.2 %, освоен 1 навык» | Видимый маленький прогресс — сильнейший драйвер (Amabile & Kramer) | внедряется |
| **Напоминание решать на бумаге** на многошаговых задачах | Экзамен письменный; у рукописи больше нейронных связей (Frontiers 2023), хотя прямых данных по многошаговой алгебре нет — это страховка, не догма | внедряется |

## Что делаем следующим этапом

| Решение | Почему |
|---|---|
| **Пробный экзамен как «босс»**: 60 минут, все пройденные темы вперемешку, видимый таймер, без подсказок | Главный разрыв — «умею на тренировке / не умею на экзамене» (Wharton RCT 2024). Таймер не прятать: связь «таймер → тревога» в исследованиях не подтверждается (Maki 2024) |
| **Журнал ошибок, который сам возвращает задачу** | Обычные «журналы ошибок» не работают, потому что только каталогизируют; работает только автоматический повтор того же типа |
| **JSXGraph** для интерактивов по векторам и геометрии (неделя 2) | Двойная лицензия LGPL/MIT, активно развивается, экономит недели работы |
| **PhET-симуляции** для механики и термодинамики (недели 13–14) | CC BY 3.0, официально разрешено скачивать и встраивать офлайн |
| **Набор проверок в стиле STACK** (единицы измерения, «упрощено ли», системы уравнений) | Берём дизайн проверок, не код (у STACK GPL) |
| **Задачи OpenStax (CC BY)** как источник формулировок для недель 5–14 | Легально адаптировать с указанием источника |

## Что решили не делать

- **Свободный ИИ-решатель.** В полевом RCT (Wharton, 2024) доступ к GPT-4 поднял результаты домашки на 127 %, но на закрытом экзамене группа показала ровно столько же, сколько без него. Если добавим подсказки от Claude — только после зафиксированной попытки, с понижением оценки навыка.
- **ИИ-проверка фото с рукописным решением.** Модели систематически ошибаются в диагностике именно слабых решений (EMNLP 2025, DrawEduMath) — ложная обратная связь хуже её отсутствия.
- **Прятать таймер** на пробных экзаменах.
- **Ставки деньгами** (Beeminder-подобное): доказательная база — самоотчёты компании, а для этого пользователя это ещё и давление.
- **Лиги и рейтинги** (решено в первом круге).
- **ALEKS-подобная модель знаний / BKT поверх FSRS** — граф из 125 навыков уже даёт практическую пользу от этой идеи; добавлять вторую модель для одного ученика избыточно.

## Замечание про лицензии

WeBWorK OPL, MyOpenMath, LibreTexts — CC BY-NC-SA: для личного некоммерческого использования подходит, но нельзя публиковать приложение с их задачами внутри. Maxima, Mathics (GPL) и p5.js (LGPL) — не собирать в бандл. GeoGebra бесплатна только для некоммерческого использования. PhET (CC BY) и OpenStax (CC BY у большинства книг) — самые чистые источники.

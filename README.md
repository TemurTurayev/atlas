# Атлас

Тренажёр по математике и физике под экзамен **MQLS-CO-01 Guided Self-Study (Math/Physics)** — 60 минут, порог 45 %.
Условия задач на английском, как на экзамене; объяснения на русском.

## Запуск

```bash
npm install     # один раз
npm run dev     # откроется http://localhost:5173
```

## Как это работает

- **Старт с базы.** Каждый новый навык начинается с экспресс-проверки: две задачи без урока. Решил обе — навык засчитан, идём дальше. Ошибся — включается урок: теория → разобранный пример → пример с пропусками → практика.
- **Прыжок.** Три экспресса подряд — приложение предложит проверить тему на несколько шагов вперёд. Решишь две задачи — всё, что к ней ведёт, зачтётся.
- **Ремонт.** Две ошибки подряд на лёгком уровне или проваленное повторение — и приложение само проверит темы, на которых этот навык стоит, и починит пробел.
- **Повторения.** Каждый освоенный навык возвращается по расписанию FSRS: чем ближе экзамен, тем короче интервалы. Задача каждый раз новая.
- **Прогноз.** Главная цифра — предсказанный балл на экзамене с отметкой порога 45 %. Вторая шкала — школьная база.
- **Серия.** День засчитывается после 5 решённых задач. Есть две «заморозки» на пропуски.

## Установка как приложение на Mac

Пока приложение работает локально (`npm run dev`), окно Dock не получится: для этого нужен постоянный адрес.
После публикации (GitHub Pages) — Safari → меню «Файл» → «Добавить в Dock». На iPhone: «Поделиться» → «На экран Домой».

## Резервная копия

Прогресс хранится только в браузере (IndexedDB) и никуда не отправляется. Раз в неделю: **Настройки → Сохранить копию** (скачается JSON).
Восстановление — там же, «Восстановить из копии».

## Разработка

```bash
npm test          # юнит-тесты (ядро, проверка ответов, генераторы задач)
npm run typecheck # tsc --noEmit
npm run build     # сборка в dist/
npm run e2e       # браузерный смоук-тест (нужен npx playwright install chromium)
```

Структура:

```
src/core/graph/        125 навыков: зависимости, «лестница» изучения
src/core/templates/    генераторы задач (week0 = школьная база, week1… = недели курса)
src/core/checker/      проверка ответов (единственное место, решающее «верно/неверно»)
src/core/learner/      состояния навыка: экспресс, урок, уровни, прыжок, ремонт
src/core/scheduler/    интервальные повторения (FSRS)
src/core/session/      сборка ежедневного забега
src/data/              хранение прогресса (Dexie/IndexedDB)
src/ui/                экраны и компоненты
docs/specs/            спецификация
docs/plans/            планы реализации
docs/research/         граф навыков, механики, наука обучения
```

Новый навык добавляется одним файлом в `src/core/templates/week<N>/`: общий тест-стенд `harness.test.ts` сам проверит
детерминированность, отрисовку формул и то, что проверяльщик принимает эталонный ответ и отвергает искажённый.
